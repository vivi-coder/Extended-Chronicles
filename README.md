# 📖 Extended Chronicles

[![Discord](https://img.shields.io/badge/Discord-Join%20Us-5865F2?logo=discord&logoColor=white)](https://discord.gg/Kn2cC6vwTU)

> A Visual Novel project based on **The Evillious Chronicles**.

---

##  About The Project

**Extended Chronicles** is a community-driven visual novel adaptation inspired by the lore and stories of *The Evillious Chronicles* (mothy / Seven Sins Series). 

Our goal is to extend it.

---

##  Features

- Dive deep into adapted and expanded stories inspired by Evillious lore.
- Featuring character sprites, background art and music.
- Built by contributors, made for everyone

---


### How to install

Join the Discord or check Github Releases
There will be .apk and .exe in order to run the game
iOS is NOT supported, only on the final build
